# 🍔 Nutrition Label

A detailed nutrition facts label built with HTML and CSS, demonstrating advanced typography and text styling techniques.

## 📖 About
Sixth project from freeCodeCamp's Responsive Web Design certification. A replica of a standard nutrition label focusing on typography, text formatting, and precise layout control.

## 🛠️ Built With
- HTML5 (Semantic markup)
- CSS3 (Typography, Text styling)

## 💡 Key Learnings
- **Typography fundamentals** (font-family, font-size, font-weight)
- Line-height and letter-spacing
- Text alignment and formatting
- Border styling (solid, dotted dividers)
- Semantic HTML for structured data
- Precise spacing and padding control
- Creating print-style layouts for web
- Font rendering and readability

## 🎯 Features
- Accurate nutrition label replica
- Clean, readable typography
- Proper use of borders and dividers
- Structured data presentation
- Professional document styling
- Attention to spacing and alignment
